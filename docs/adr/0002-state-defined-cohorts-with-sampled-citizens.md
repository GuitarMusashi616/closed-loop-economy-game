# State-defined cohorts with sampled citizens

Citizens (about 100,000) are simulated as Household Cohorts defined by state (age band, skill, employment, wealth band), with citizens moving between cohorts as their state changes. Results are exact in aggregate, and zooming in shows a Citizen sampled deterministically from the cohort's distribution. We rejected per-citizen simulation for performance and UI noise. The cost is that individuals have no persistent identity, though "notable citizens" could be added later.
